# Research and historical experiments

Historical live-CATIA investigations (COM interface probes, Non-Semantic GD&T frame/ROI prototypes, OCR v6x/v7x experiments) are retained under `tests/integration/` for reproducibility and audit. They are not part of the default offline test suite and should be run only against an appropriate CATIA test environment.

This folder is reserved for future dated research notes, sanitized example diagrams and experiment analyses. Do not add proprietary CATPart models, raw screen captures, engineering reports, or reviewer data to Git.
